# Electricity Bill Calculator

A beginner C program that calculates an electricity bill using sample tariff slabs.

## 🛠️ Language Used

- C

## 📚 What I Learned

- Variables
- `scanf()`
- `printf()`
- Arithmetic calculations
- `if` and `else`
- Basic programming logic

## ⚡ How It Works

1. Enter the electricity units consumed.
2. The program calculates the bill using sample tariff rates.
3. It displays the total electricity bill.

## 🎯 Purpose

This is a beginner project created while learning C programming as an EEE student.
